궁금한 점이 있나요?

사용할 때 어떤 제한이 있나요?

FocusShade의 가림 영역은 클릭을 차단하지 않습니다. 보안이나 개인정보 보호용으로 사용하지 마세요. 일부 단축키 충돌은 감지하지 못할 수 있습니다. MenuFold는 아이콘을 왼쪽으로 밀어 숨기며, 별도 드롭다운이나 가로 스크롤은 제공하지 않습니다. 노치가 있거나 화면이 작으면 펼쳐도 아이콘이 모두 보이지 않을 수 있습니다.

자동 실행과 업데이트는 어떻게 하나요?

MenuFold를 응용 프로그램 폴더에 설치한 뒤 설정에서 ‘로그인 시 자동 실행’을 켜세요. 승인 대기 상태라면 시스템 설정의 로그인 항목에서 허용하세요. 자동 업데이트는 없습니다. 업데이트하거나 삭제할 때는 자동 실행을 끄고 앱을 종료한 뒤 교체·삭제하세요.

개인정보를 수집하나요?

현재 앱에는 네트워크 전송, 광고, 분석 SDK 및 계정 기능이 없습니다. 설정은 Mac에 저장합니다. 이 웹사이트는 GitHub Pages에서 제공하며 GitHub는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 내용은 FocusShade · MenuFold 개인정보 안내와 GitHub 개인정보 처리방침에서 확인하세요.

문제나 개선 아이디어는 어디에 보내나요?

GitHub Issues로 알려주세요. 앱 이름과 버전, Mac 칩, macOS 버전, 문제 재현 순서를 함께 적으면 도움이 됩니다. 스크린샷에서는 개인정보를 가려주세요.
