Software Engineer

제품을 이해하고, 운영 가능한 소프트웨어로 만듭니다.

복잡한 문제를 작은 단위로 쪼개고, 사용자가 실제로 만나는 흐름까지 책임지는 일을 좋아합니다. 백엔드, 운영 도구, 자동화, 학습 시스템을 만들며 좋은 의사결정이 코드와 문서에 남도록 일합니다.

About GitHub
Focus

시스템의 끝까지 봅니다.

API 하나를 추가하더라도 데이터 모델, 관리자 화면, 배포, 로그, 운영자가 확인할 수 있는 상태까지 함께 봅니다. 구현 자체보다 오래 유지되는 흐름을 만드는 데 관심이 있습니다.

Working Style

작게 검증하고 빠르게 정리합니다.

불확실한 부분은 실제 코드와 실행 결과로 확인합니다. 결정한 내용은 문서와 저장소에 남기고, 다음 사람이 같은 맥락을 다시 추적하지 않도록 정리합니다.

Interests

제품, 자동화, 학습 도구.

반복되는 일을 자동화하고, 지식을 실제 실행으로 이어지게 만드는 도구에 관심이 많습니다. 좋은 도구는 사람의 판단을 흐리게 하지 않고 더 선명하게 만든다고 믿습니다.

최근에 다루는 주제

  • Backend architecture and operational reliability
  • Admin tools that expose real product state
  • Automation workflows for development and learning
  • Knowledge systems that turn notes into practice
