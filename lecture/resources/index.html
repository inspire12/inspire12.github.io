  • Raft · 시뮬레이터

  • Sam Rose · 시뮬레이션

    Load Balancing

    서버 한 대만 응답이 느려지면 라운드 로빈은 어떻게 동작할까요? 요청이 쌓이는 모습을 보고 최소 연결 방식과 지연 분포를 비교합니다.

  • Hello Interview · 해시 링 도식

  • Amazon Builders’ Library · 운영 사례

    Caching challenges and strategies

  • AWS Architecture Blog · 시뮬레이션 결과

    Exponential Backoff and Jitter

  • Hello Interview · 설계 면접

    Design Facebook’s News Feed

    게시할 때 피드를 미리 만드는 방식과 조회할 때 합치는 방식의 읽기·쓰기 비용을 비교합니다. 팔로워가 많은 계정에도 같은 방식을 쓸지 면접 질문으로 이어갑니다.

네트워크

DNS 조회와 캐시

  • Cloudflare Learning Center · 조회 흐름도 · 한국어

    DNS란 무엇인가요?

    캐시가 비었을 때 재귀 리졸버가 루트, TLD, 권한 있는 네임서버에 묻는 순서를 그립니다. 같은 이름을 다시 조회하면 어느 단계까지 생략되는지 짚어봅니다.

  • Google Admin Toolbox · DNS 조회 실습

    Dig (DNS lookup)

    같은 도메인의 A, MX, NS를 차례로 조회합니다. 웹 서버 주소, 메일을 받을 서버, 해당 도메인을 담당하는 네임서버가 응답에서 어떻게 구별되는지 읽어봅니다.

  • Julia Evans · Marie Claire LeBlanc Flanagan · DNS 실험실

    Mess With DNS

    발급된 실습용 서브도메인에 레코드를 만들고 조회합니다. 값을 바꾼 뒤 응답과 권한 서버의 요청 로그를 대조하며 TTL 동안 캐시가 미치는 영향을 관찰합니다.

TCP · TLS · 인터넷 라우팅

  • Ilya Grigorik · High Performance Browser Networking · 패킷 흐름도

    Building Blocks of TCP

    SYN, SYN-ACK, ACK를 시간축에 표시합니다. 왕복 지연이 100ms인 경우 새 TCP 연결로 첫 요청을 보내기까지 얼마나 걸릴지 계산합니다.

  • Cloudflare Learning Center · 프로토콜 해설 · 한국어

    TLS 핸드셰이크란?

    TLS 1.3의 첫 연결에서 ClientHello와 서버 응답을 따라갑니다. 서버 인증서를 확인하는 단계와 애플리케이션 데이터를 주고받기 위한 키를 만드는 단계를 구분합니다.

  • Cloudflare Radar · BGP 대시보드

    Routing Information Worldwide

    날짜 범위를 정하고 IPv4와 IPv6의 공지 주소 공간 그래프를 전환합니다. AS 순위가 고객망 규모를 기준으로 할 때와 주소 공간을 기준으로 할 때 어떻게 달라지는지 봅니다.

  • Markus Winand · Use The Index, Luke · 인덱스 설계 예제

  • Dalibo · 실행 계획 시각화
