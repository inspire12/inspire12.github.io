팀 응원 커뮤니티 피드

팀별 게시글을 무한 스크롤로 읽고 사진만 따로 모아볼 수 있는 KBO 팬 커뮤니티를 개발했습니다.

#무한 스크롤#이미지 리사이징#비동기 처리

이미지 업로드와 비동기 변환

팬이 올린 사진은 게시글 피드와 이미지 모아보기에서 함께 쓰였습니다. 이미지 처리를 공통 API로 묶고, 업로드와 크기 조정을 분리했습니다. 업로드 요청이 이미지 변환을 마칠 때까지 기다릴 필요가 없도록 했습니다.

업로드한 파일은 종류에 따라 후속 작업이 달랐습니다. 이미지는 피드에 쓸 크기로 자동 조정했고, 영상은 비동기로 변환했습니다.

커뮤니티 기능과 공통 API

게시글에 댓글을 달고 투표나 이모티콘으로 참여하는 기능, 운영자가 사용자를 제재하는 기능을 만들었습니다. 댓글도 공통 도메인과 API로 정리해 여러 서비스에서 재사용할 수 있게 했습니다.
