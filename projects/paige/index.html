NCSOFT · NLP 서비스 개발팀

PAIGE

KBO 경기 중계와 하이라이트, 팀별 팬 커뮤니티를 제공하는 PAIGE의 백엔드를 개발했습니다.

#실시간 경기 중계#스포츠 데이터 워크플로#추천 데이터 파이프라인#서비스 모니터링#Mock 서버

이닝이 끝난 뒤 기록이 바뀌면

기록원이 이전 이닝의 판정을 정정하면 이미 만든 중계 문구와 영상에 옛 기록이 남았습니다. 당직 개발자가 매번 데이터를 다시 생성해야 해서 이 작업의 자동화를 제안했습니다.

마지막 이닝만 보면 이전 이닝의 정정을 놓칩니다. 한 경기의 데이터가 많아도 약 200~300건이어서, 수집할 때 당일 경기 API 응답 전체를 DB에 저장한 기록과 비교했습니다. 달라진 내용을 기록하고 정정 유형에 따라 관련 콘텐츠를 다시 생성하도록 했습니다.

실제 경기 데이터를 순서대로 재생하는 모의 서버에서 이닝 종료 이벤트 처리가 누락되는 상황을 재현했습니다. 선수 교체와 기록 적재가 잘못되는 오류를 수정하고, 운영 어드민에서도 처리 상태를 확인할 수 있게 했습니다.

PAIGE의 다른 백엔드 작업

  • 홈 피드의 추천 지연을 응원 팀별 캐시로 줄인 과정
  • 팀 응원 커뮤니티의 이미지 피드와 비동기 변환
  • 경기 일정에 맞춰 푸시를 예약하고 발송하는 구조
