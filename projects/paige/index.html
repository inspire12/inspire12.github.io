NCSOFT · NLP 서비스 개발팀

PAIGE

KBO 경기 중계와 하이라이트, 팀별 팬 커뮤니티를 제공하는 PAIGE의 백엔드를 개발했습니다.

#실시간 경기 중계#스포츠 데이터 워크플로#추천 데이터 파이프라인#서비스 모니터링#Mock 서버

기술 역량

실시간 경기 중계와 영상

실시간 경기 중계와 스트리밍, 경기·뉴스 데이터 처리 흐름을 다뤘습니다. 기록원이 입력한 경기 데이터가 이닝이 끝난 뒤 수정되면 중계에 오류가 전파될 수 있었습니다. 수집 중에 데이터 변경을 감지하고 기록해 수정 사항을 반영할 수 있게 했습니다.

Mock 서버로 오류 상황을 재현할 수 있는 테스트 환경을 만들었습니다. 영상 재생성 로직을 개선하고, 어드민에서 상황을 모니터링할 수 있게 했습니다.

추천 데이터 파이프라인과 홈 피드

서비스에서 나온 데이터를 AI 팀의 Curation Platform에 넘기고, 추천 결과를 받아 홈 피드를 구성했습니다. 추천 API 지연이 홈 피드에 영향을 주는 문제를 그룹별 캐시와 배치 갱신으로 개선했습니다.

팀 응원 커뮤니티

KBO 팀별 팬 커뮤니티의 게시글, 댓글, 투표, 이모티콘과 사용자 제재 기능을 개발했습니다. 댓글과 이미지를 공통 도메인과 API로 정리해 여러 곳에서 재사용할 수 있게 했고, 무한 스크롤과 미디어 자동 변환을 구현했습니다.

경기 일정에 맞춘 푸시

경기 일정에 맞춰 푸시를 예약하고, 운영자가 대상 그룹별로 문구를 편집하거나 발송을 취소할 수 있는 어드민을 개발했습니다. 워커가 푸시 발송을 처리했고, 사용자 응답 데이터를 AI Lab 추천 모델의 피드백으로 연결했습니다.
