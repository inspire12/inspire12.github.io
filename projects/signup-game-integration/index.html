#계정 가입#게임 계정 연동

계정 운영 도구 개선

기존 계정 시스템에 연결하는 Java API 서버와 운영 어드민을 개발했습니다. 운영자가 계정 권한과 2차 인증 상태를 조회하고 관리하는 API와 화면을 개선했습니다.

BATTLE CRUSH 출시 지원

BATTLE CRUSH 출시 때 방송을 본 시청자에게 게임 아이템을 지급하는 Twitch Drops를 연동했습니다. Twitch에서 보상을 받은 시청자가 게임에서 아이템을 받으려면, Twitch 계정과 보상을 지급할 게임 계정이 연결되어 있어야 했습니다.

시청에서 아이템 지급까지

  1. 시청자가 Drops에 참여한 스트리머의 BATTLE CRUSH 방송을 보고 시청 조건을 충족합니다.
  2. 시청자가 Twitch에서 Drops 보상 수령을 신청합니다.
  3. 게임은 Twitch 계정에 연결된 게임 계정에 아이템을 지급합니다.

저는 출시 과정에서 계정 연동을 지원하고, Twitch에서 받은 보상이 게임 안에서 아이템으로 이어지도록 연동 작업을 맡았습니다.
