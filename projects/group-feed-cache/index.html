추천 피드의 그룹별 캐싱

PAIGE 홈 피드의 추천 결과를 그룹 단위로 재사용하도록 바꿨습니다.

#그룹 단위 캐싱#추천 피드

문제 인식

홈 피드를 열 때 사용자별로 추천 API를 실시간 호출했습니다. 추천 응답이 늦어지거나 타임아웃이 나면 홈 피드 응답도 영향을 받았습니다.

작업 및 결과

여러 컴포넌트에서 보내는 데이터를 culogger 서버에서 모았습니다(fan-in). 데이터 포맷을 맞춘 뒤 AI 팀의 Curation Platform으로 전달했고, 돌아온 추천 결과로 홈 피드를 구성했습니다.

추천 결과는 그룹별로 캐싱하고 배치로 갱신했습니다. 같은 그룹의 사용자는 캐시된 피드를 받아, 화면을 열 때마다 추천 API 응답을 기다릴 필요가 줄었습니다. 서킷브레이커도 적용해 추천 API 장애가 홈 피드로 전파되는 범위를 줄였습니다.
