썸원타임 질문 알림 문구 다양화

어떤 알림 문구에 사용자가 반응하는지 비교하려고, 썸원타임 푸시에 사용자별로 다른 문구를 적용했습니다.

#알림 문구#문구 캐싱

같은 질문 알림에 다른 문구를 보내려면

썸원타임은 커플에게 오늘의 질문이 도착했음을 알리는 푸시입니다. 문구를 실험하려면 사용자에게 배정된 문구가 실제 발송까지 이어져야 했습니다. 같은 문구를 쓰는 알림마다 파일을 다시 가져올 필요도 없었습니다.

Hackle에서 배정하고 발송 시 파일을 재사용

알림 문구 파일을 Amazon S3에 미리 저장하고, 사용자마다 어느 파일을 사용할지 Hackle로 정했습니다.

발송할 때는 배정된 파일을 캐시에서 먼저 찾았습니다. 캐시에 없을 때만 S3에서 읽어 저장했습니다. 같은 파일을 배정받은 사용자에게는 캐시에 있는 문구를 곧바로 쓸 수 있었습니다.
