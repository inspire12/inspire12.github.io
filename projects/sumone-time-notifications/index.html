썸원타임 질문 알림 문구 다양화

사용자별로 문구 파일을 선택해 썸원타임 알림에 서로 다른 문구를 보여줄 수 있도록 했습니다.

#알림 문구#문구 캐싱

문제 인식

썸원타임은 썸원에서 질문이 도착했음을 알려주는 알림입니다. 이 알림의 문구를 다양화하려면 어떤 사용자에게 어느 문구 파일을 적용할지 정하고, 발송할 때 해당 파일을 읽을 수 있어야 했습니다.

작업 및 결과

알림 문구 파일을 Amazon S3에 미리 저장하고, 사용자마다 어느 파일을 사용할지 Hackle로 정했습니다.

알림을 보낼 때는 선택한 파일이 캐시에 있는지 먼저 확인했습니다. 캐시에 파일이 있으면 그대로 사용하고, 없으면 S3에서 읽어 캐시에 저장한 뒤 알림에 적용했습니다.
