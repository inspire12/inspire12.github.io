NCSOFT Account Platform

계정 보안 로그 분석 대시보드

보안 레벨을 조정할 판단 근거를 마련하기 위해 사용자 활동과 보안 지표를 30분 단위로 볼 수 있는 대시보드를 설계했습니다.

#계정 보안#보안 로그 분석#관측성

문제 인식

공격 상황에 대응해 계정 보안 레벨을 조절할 수 있는 기능이 추가됐습니다. 당시에는 계정 활동과 보안 로그를 충분히 모니터링할 수 없어, 어떤 상황에서 보안 레벨을 조정할지 기준을 세우기 어려웠습니다.

작업 및 결과

운영자가 인증 성공과 실패 추이를 함께 볼 수 있도록 지표를 정의했습니다. Kafka로 들어온 보안 로그는 Airflow에서 1차 저장하고, 30분 단위 통계로 집계해 InfluxDB에 저장했습니다. 집계한 지표는 Grafana 대시보드와 사내 어드민 페이지에서 확인할 수 있도록 연동했습니다.

운영할 때는 배치 실행 상태와 실제 데이터 적재 상태를 각각 확인할 수 있게 했습니다. 집계를 다시 만들어야 할 때는 대상 기간을 지정해 Airflow 백필로 재처리할 수 있었습니다.
