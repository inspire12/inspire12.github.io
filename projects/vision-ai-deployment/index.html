Vision AI 모델 서빙과 배포 자동화

Vision AI 팀의 모델을 API로 호출할 수 있게 만들고 Kubernetes 배포 과정을 자동화했습니다.

#모델 서빙#CI/CD

모델 교체 때마다 필요했던 수동 배포

Vision 모델을 수동 배포하고 있어 버전마다 테스트하기 어렵고, 문제가 생기면 이전 버전으로 되돌리기도 쉽지 않았습니다.

모델 버전에서 GPU 배포까지

Vision AI 팀이 개발한 모델을 서비스에 올리는 쪽을 맡았습니다. 추론을 호출할 FastAPI 서버를 만들고 컨테이너화했습니다. 모델 버전 관리와 GPU 기반 Kubernetes 배포를 하나의 CI/CD 흐름으로 연결해 새 버전도 같은 절차로 배포할 수 있게 했습니다.

실시간 선수 분석 영상 서비스는 이 API를 호출해 모델 결과를 받았습니다.
