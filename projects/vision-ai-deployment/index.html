NCSOFT · Vision AI 팀 협업

Vision AI 모델 서빙과 배포 자동화

Vision AI 팀의 모델을 API로 호출할 수 있게 만들고 Kubernetes 배포 과정을 자동화했습니다.

#모델 서빙#CI/CD

문제 인식

Vision 모델을 수동 배포하고 있어 버전마다 테스트하기 어렵고, 문제가 생기면 이전 버전으로 되돌리기도 쉽지 않았습니다.

작업 및 결과

서비스에서 모델을 호출할 수 있도록 FastAPI 서버를 만들고 컨테이너화했습니다. 모델의 버전을 관리하는 단계부터 GPU 기반 Kubernetes 배포까지 이어지는 CI/CD 파이프라인을 구축했습니다.

이 파이프라인을 통해 수동으로 제공하던 실시간 선수 분석 영상 서비스의 배포와 운영 과정을 자동화했습니다.
