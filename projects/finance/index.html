금융 AI 서비스

주식 데이터 처리와 모델 서빙을 다루며 자기자본 투자 업무를 지원했습니다.

#모델 서빙#금융 데이터

문제 인식

주식 데이터를 다루는 배치는 증권시장 일정에 맞춰 실행해야 했습니다. 시장 일정에 따라 어느 배치를 실행할지 정하는 과정이 필요했습니다.

작업 및 결과

증권시장 일정을 확인하고, 해당 일정에 필요한 작업을 골라 실행하는 상위 배치 워크플로를 설계했습니다.

저장 단계에서는 Java 리플렉션을 적용해 배치마다 다루는 데이터 유형에 맞춰 여러 건을 일괄 저장할 수 있도록 했습니다.
