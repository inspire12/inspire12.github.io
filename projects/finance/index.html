NCSOFT · 금융AI서비스 개발팀

금융 AI 서비스

주식 데이터 처리와 모델 서빙을 다루며 자기자본 투자 업무를 지원했습니다.

#모델 서빙#금융 데이터#Mock 서버

문제 인식

주식 데이터 배치는 증권시장 일정에 맞춰 실행해야 했습니다. 장이 끝난 뒤에는 실제 시장 이벤트로 매매 흐름을 확인하기도 어려웠습니다.

작업 및 결과

시장 일정에 맞춘 배치 실행

증권시장 일정을 확인해 필요한 작업만 골라 실행하는 상위 배치를 설계했습니다.

배치 데이터 일괄 저장

배치마다 다루는 데이터 유형에 맞춰 여러 건을 한 번에 저장할 수 있도록 Java 리플렉션을 적용했습니다.

장 마감 후 매매 테스트

매매 시나리오를 재현하는 Mock 서버를 만들었습니다. 팀원은 장 운영 시간과 관계없이 개발과 테스트를 이어갈 수 있었습니다.
