앱스토어 결제 및 환불

오브제 등을 살 수 있는 앱 상점에서 Apple App Store와 Google Play의 인앱 결제 및 환불을 다뤘습니다.

#인앱 결제#환불 처리

문제 인식

스토어에서 구매가 환불되면 앱 서버에도 거래 상태를 반영해야 했습니다. 같은 환불이라도 Apple App Store와 Google Play는 알림을 보내는 방식과 메시지에 담기는 거래 정보가 달랐습니다.

  • Apple App Store는 등록한 서버 URL로 App Store Server Notifications V2를 보냅니다. 스토어가 거래를 환불하면 REFUND 알림이 오고, JWS로 서명된 signedPayload에 알림 유형과 거래 정보가 담깁니다.
  • Google Play는 Cloud Pub/Sub를 통해 실시간 개발자 알림(RTDN)을 보냅니다. VoidedPurchaseNotification에는 구매 토큰, 주문 ID, 상품 유형, 환불 유형이 담깁니다. 전체 거래 상태가 필요하면 Google Play Developer API로 조회합니다.

작업 및 결과

제가 맡은 부분은 환불 알림을 받아 서버에서 처리하는 일이었습니다. AWS API Gateway에 알림 구독용 경로를 지정하고, 그 경로로 들어온 환불 요청을 서버의 환불 처리로 연결했습니다.

공식 문서

  • Apple · App Store 서버 알림 유형 — 환불과 구독 상태 변경 이벤트
  • Apple · App Store 서버 알림 V2 본문 — 서명된 알림과 거래 데이터
  • Google Play · 실시간 개발자 알림 — 환불·취소 알림의 필드
  • Google Play · RTDN 설정 — Cloud Pub/Sub 구독을 통한 알림 수신
  • AWS · API Gateway 라우팅 — 요청 경로를 백엔드에 연결하는 방식
