시스템 디자인 기술 면접

라이브 강의 서비스를 설계하며 아홉 가지 결정을 내려봅니다. 각 면접에서 먼저 90초 동안 답해 본 뒤, 예시 답변과 두 가지 꼬리질문으로 설계를 점검해 보세요.

첫 면접 시작하기

면접 목차

  1. 네트워크 기초점수판을 보는 3만 명에게 변경 사항을 어떻게 보낼까요?
  2. API 설계신청은 성공했는데 응답이 사라졌습니다. 다시 누르면 어떻게 되나요?
  3. 데이터 모델링강의 가격은 바뀌어도 지난 신청 내역의 금액은 그대로여야 합니다.
  4. 데이터베이스 인덱싱신청 20건만 반환하는데 8만 행을 읽습니다. 어떤 인덱스를 제안할까요?
  5. 캐싱잔여 좌석 1석을 5천 명이 동시에 보고 있습니다. 무엇을 캐싱할까요?
  6. 샤딩회차 ID로 나눈 샤드 하나에 전체 쓰기의 60%가 몰렸습니다.
  7. 일관 해싱캐시 노드를 한 대 늘릴 때 어떤 키의 담당자가 바뀔까요?
  8. CAP 정리지역 간 통신이 끊겼습니다. 두 지역 모두 마지막 좌석을 확정해도 될까요?
  9. 용량 산정조회가 열 배 몰리는 10분을 서버 몇 대로 버틸 수 있을까요?

내 연습 기록
